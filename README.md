# Week 1 Database Assignment

## Topic

Library Management System

## Description

This project contains a MySQL database script that creates a library management database named `library_management`. The database stores authors, books, library members, and book loans.

## Database Structure

- `authors`: Stores author names.
- `books`: Stores book details and references an author.
- `members`: Stores library member information.
- `loans`: Records which member borrowed which book and when.

## How to Run

1. Open MySQL Workbench or a MySQL terminal.
2. Run the contents of `answer.sql`.
3. The script creates the database, tables, and sample records automatically.

## File

- `answer.sql`: SQL commands for creating and populating the database.
